# Exportador de Fotos para Redes Sociais

Versão portuguesa da aplicação para carregar até 150 fotografias, aplicar um logótipo ou uma moldura APCM e exportar imagens e vídeos nos formatos das redes sociais.

Criado por Susana Quintal.

## Abrir

- No computador: `http://127.0.0.1:8765/pt/`
- Na internet: `https://suqui13.github.io/socialmedialogo/pt/`

Para usar offline, abra primeiro a aplicação através de `START-APP.cmd` ou do atalho instalado por `INSTALL-MICROAPP.cmd`.

As fotografias e os logótipos são processados localmente no navegador. A deteção facial procura apenas a posição dos rostos para evitar cortes e não identifica pessoas.
